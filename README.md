# Little wishes

짙은 플럼 무대, 핑크 포인트, 입체 케이크와 다섯 개의 촛불을 중심으로 한 생일 페이지 디자인. 정적 HTML/CSS/JavaScript로 GitHub Pages에 배포할 수 있습니다.

로컬 실행: `python -m http.server 4173` 후 http://localhost:4173

케이크는 독립 PNG, 초 몸통·심지·불꽃·연기는 각각 HTML/CSS 요소입니다. 불꽃마다 다른 주기로 흔들리며 버튼을 누르면 꺼지고 연기가 올라옵니다. 마이크 소리 크기 감지와 버튼으로 촛불을 끌 수 있는 디자인 프로토타입입니다.

에셋: `assets/birthday-cake.png`. 내장 imagegen 생성 프롬프트: 작은 1단 바닐라 케이크, 체리 3개와 크림 장식, 얇은 핑크 크림 띠, 낮은 접시, 부드러운 입체 재질, 투명 배경. 초·불꽃·리본·진주·곰·글자 없음.

## 파티 시나리오
파티 시작 → 축하 인트로와 입장 음악 → 케이크 등장과 생일 축하 멜로디 전체 재생 → 소원 빌기 → 마이크 또는 버튼으로 촛불 끄기 → 소원 성취 축하.

`?name=홍길동` 쿼리로 이름을 지정합니다. 음악은 Web Audio 합성 반주이며 보컬 음원은 포함하지 않습니다. 마이크는 버튼을 눌러 허용한 경우만 사용하며 소리 크기를 감지합니다. 소리를 녹음하거나 서버로 전송하지 않습니다. 큰 주변 소리에도 반응할 수 있습니다.

## 도파# 브랜드 프레임

`dopasharp/` 폴더는 모든 dopa.shap 게임 저장소에 **똑같이** 복사해 쓰는 공통 디자인 시스템(v1.1)입니다. 원본은 `soju-game/dopasharp/`이고, 여기서 고치지 말고 원본을 고친 뒤 모든 저장소에 다시 복사합니다. 게임 화면 색은 각 게임이 유지하고, 시작·결과·공유·다른 게임 이동·하단 브랜드 표시만 통일합니다.

- `tokens.css` — 색상·타이포·여백·모서리·모션 토큰.
- `components.css` — 헤더, 버튼(Primary/Secondary/Tertiary), 게임 카드, 결과 시트, 푸터.
- `dopasharp.js` — 게임 목록(`GAMES`, 허브 `games.js`와 같은 순서), 결과 시트 `DopaSharp.showResult()`, "다른 게임 보기" → 허브 /games/ 연결, 공통 분석 이벤트 `DopaSharp.track()`.

링크 미리보기 이미지는 `og/birthday.html`을 고친 뒤 `og/birthday.png`로 다시 렌더링합니다 (명령은 파일 맨 위 주석 참고).
